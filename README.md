# project2

1. 프로젝트 소개

AI 철학자 아고라는 인공지능을 활용하여 다양한 철학자들과 대화하고, 철학적 주제에 대해 토론할 수 있도록 만든 웹 애플리케이션이다.

니체, 소크라테스, 장자, 칸트, 홉스 총 5명의 철학자를 구현하였으며, 각 철학자의 대표적인 사상뿐만 아니라 성격과 말투까지 AI에 반영하였다.

프로젝트는 크게 두 가지 기능으로 구성된다. 먼저 사용자가 원하는 철학자를 선택하여 일대일로 대화할 수 있으며, 다섯 명의 철학자가 하나의 주제를 놓고 서로 의견을 나누는 그룹 토론도 진행할 수 있다. 이를 통해 하나의 문제를 여러 철학적 관점에서 바라보고, 평소 어렵게 느껴졌던 철학을 보다 친숙하게 접할 수 있도록 하였다.

2. 사용법

-철학자와 개별 대화하기

웹 애플리케이션에 접속한 후 왼쪽 사이드바에서 대화하고 싶은 철학자를 선택한다. 선택한 철학자의 주요 사상과 특징을 확인한 뒤 하단의 채팅 입력창에 궁금한 점이나 토론하고 싶은 주제를 입력하면 된다. AI는 해당 철학자의 사상과 말투를 반영하여 답변하며, 이전 대화 내용을 바탕으로 질문을 이어갈 수 있다.

-철학자 그룹 토론하기

토론 주제 입력창에 원하는 주제를 작성하고 ‘채팅방 입장 및 토론 시작’ 버튼을 누른다. 그러면 다섯 명의 철학자가 차례로 자신의 관점에서 의견을 제시하고, 이후 서로의 주장을 언급하며 반박과 토론을 이어간다. 토론 중간에는 추가 토론을 진행할지, 바로 사회자의 요약을 확인할지 선택할 수 있다. 토론이 종료되면 사회자가 각 철학자의 입장과 핵심 주장을 정리해 보여준다.

3. 주요 기능 설명

-철학자 선택 및 개별 대화

사용자가 원하는 철학자를 직접 선택하고 자유롭게 대화를 나눌 수 있는 기능이다. 니체의 초인과 권력의 의지, 소크라테스의 문답법, 장자의 무위자연, 칸트의 정언명령, 홉스의 사회계약론 등 각 철학자의 사상을 바탕으로 AI 페르소나를 설정하였다. 단순히 철학 지식을 전달하는 데 그치지 않고 철학자마다 다른 말투와 사고방식이 드러나도록 구성하였다. 또한 대화 기록을 유지하여 이전 질문과 답변을 바탕으로 대화를 이어갈 수 있도록 하였다.

-철학자 그룹채팅 및 상호 토론

다섯 명의 철학자가 하나의 주제에 대해 각자의 의견을 제시하고 서로 반박하는 기능이다. 최초에는 각자의 철학적 관점에서 입장을 밝히고, 이후에는 이전 발언을 참고하여 다른 철학자의 주장을 비판하거나 자신의 의견을 보충한다. 이를 통해 단순히 다섯 명의 의견을 나열하는 것이 아니라 서로 다른 사상이 부딪히는 토론을 구현하고자 하였다.

-카카오톡 스타일의 채팅 인터페이스

그룹 토론 화면은 카카오톡 채팅방을 참고하여 제작하였다. 철학자마다 고유한 아이콘과 말풍선 색상을 지정하고, 발언자 이름과 메시지 작성 시간을 표시하여 대화 참여자를 쉽게 구분할 수 있도록 하였다. HTML과 CSS를 활용해 채팅 화면을 꾸몄으며, 실제 메신저를 사용하는 것처럼 친숙한 환경에서 토론을 확인할 수 있도록 하였다.

-토론 진행 및 선택 기능

토론은 여러 단계로 나누어 진행되며, 중간에 사용자가 직접 다음 진행 방식을 선택할 수 있도록 하였다. 추가 토론을 선택하면 철학자들의 의견 교환이 이어지고, 사회자 요약을 선택하면 추가 토론 없이 최종 정리 단계로 넘어간다. 이를 통해 사용자가 원하는 만큼 토론을 살펴볼 수 있도록 구성하였다.

-I 사회자의 최종 요약

모든 토론이 끝나면 사회자가 전체 대화 내용을 바탕으로 각 철학자의 주장을 정리한다. 각 철학자가 해당 주제에 대해 찬성하는지, 반대하는지, 중립적인지를 구분하고 그 이유와 철학적 근거를 함께 제시한다. 또한 철학자별 고유한 말투와 사상을 반영하여 한 줄 결론을 작성하도록 하였다.

사용 기술

Python을 기반으로 웹 애플리케이션을 구현하였으며, Streamlit을 사용하여 화면과 사용자 인터페이스를 구성하였다. Google Gemini API를 연동하여 철학자별 답변과 토론 내용을 생성하였고, OpenAI Python SDK의 호환 API를 활용하였다. 화면 디자인에는 HTML과 CSS를 사용하였으며, GitHub를 통해 코드를 관리하고 Streamlit Cloud를 이용한 배포를 고려하였다.
